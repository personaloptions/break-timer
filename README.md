# Break Timer — Tom Smyth · Transformational Change

A break-timer overlay for virtual workshops, made for Camo Studio Web Layers.

**Live page:** https://personaloptions.github.io/break-timer/

## Links for Camo Studio scenes

| What you want | Add to the end of the address |
|---|---|
| 10-minute break, starts as soon as the scene opens, no buttons | `?min=10&clean=1` |
| 15-minute break as a small corner overlay | `?min=15&mode=corner&clean=1` |
| Timer only, no sayings | `?min=10&quotes=0&clean=1` |
| Show the workshop name | `?min=10&clean=1&workshop=Leading%20Through%20Change` |
| Change fonts (heading & sayings / timer) | `?min=10&clean=1&font=Playfair+Display&timerfont=Oswald` |

Fonts available: Fraunces, Playfair Display, Lora, Merriweather, DM Serif Display, Inter, Montserrat, Poppins, Raleway, Lato, Open Sans, Oswald, Bebas Neue, Caveat.

Keyboard shortcuts (in a browser window): Space start/pause · R reset · + / − a minute · Q sayings on/off · L layout · F full screen · S settings.
